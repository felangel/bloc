Prefer a single `MultiBlocProvider` over nested `BlocProvider` widgets.

## Rationale

`MultiBlocProvider` merges multiple `BlocProvider` widgets into one. Using
`MultiBlocProvider` improves the readability and eliminates the need to nest
multiple `BlocProvider` widgets.

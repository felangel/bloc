Avoid creating or returning a new `Bloc` or `Cubit` instance within
`BlocProvider.value`.

## Rationale

`BlocProvider.value` is meant solely to provide an **already existing** `Bloc`
or `Cubit` to a new widget subtree (e.g. across a `Navigator` route). Unlike the
default `BlocProvider(create: ...)` constructor, `BlocProvider.value` **does not
manage the lifecycle** of the provided instance and will not call `close()` when
disposed.

Instantiating a new bloc or cubit inside `BlocProvider.value` will result in
memory leaks because the instance will never be closed.
